# Rimba Trails — image assets

Images for the Rimba Trails student project (a Google Apps Script web app),
served through the jsDelivr CDN:

    https://cdn.jsdelivr.net/gh/jad-fahmi/rimba-trails-assets@<tag>/img/<path>

The site pins a release tag (for example `v1.0.0`) so cached files never change
under it. To update an image: commit it here, push a new tag, then bump the
`ASSETS` constant in the web app's `Code.gs`.

Most photographs and the layered hero artwork are borrowed from the Sabah Parks
website (sabahparks.org.my) for non-commercial, educational use only. All rights
remain with their owners.
